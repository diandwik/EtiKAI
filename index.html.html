Supported formats

1. CSV / TSV — with an optional header row: category,question,a,b,c,d,answer. Without a header the order is: question, options 1..4, answer. The answer key may be A-F, a number 1-6, or the exact option text.

category,question,a,b,c,d,answer
AI Ethics,What is a deepfake?,Synthetic media made by AI,A compression method,A text editor,A computer virus,A

2. JSON — an array of objects: {"category":"...","question":"...","options":["...","..."],"answer":"A"}. Indonesian keys (soal/opsi/kunci/kategori) are recognised too.

3. Plain text — one question per block, separated by a blank line:

Category: AI Ethics
1. What is a deepfake?
A. Synthetic media made by AI
B. A video compression method
C. A text editing app
D. A type of computer virus
Answer: A

You can also mark the correct option with a leading asterisk: *Synthetic media made by AI. Each question needs 2 to 6 options; incomplete rows are skipped automatically.
